# Disclaimer

**Unofficial community tool.** This repository contains source code and written notes only.

- It contains **no Sony firmware**, keys or download mirror links. The app reads source pages when you ask it to and keeps what it finds in your own profile; test fixtures use synthetic links. Please don't attach firmware files to issues or pull requests.
- The app reads and checks files on your computer, downloads one file from Sony's own download server when you press the button, and writes one file to a USB drive you choose. It never installs anything on a console, never formats or repartitions a drive, and never runs or unpacks a firmware file.
- A matching checksum means the file's bytes equal what a source published. It does not prove who made the file, that it is safe, or that a console will accept it.
